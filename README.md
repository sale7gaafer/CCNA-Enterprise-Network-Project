# CCNA Enterprise Network Project

## 📌 Overview
This project simulates a real-world enterprise network for a company with two branches connected together and to the Internet.

---

## 🌐 Network Design
- Two branch offices connected via WAN
- Internet connectivity for both branches
- Subnetted network

---

## 🛠️ Technologies Used

### 🔹 Routing
- Static Routing
- Dynamic Routing (RIP v2)

### 🔹 Switching
- VLAN Configuration
- Inter-VLAN Routing

### 🔹 Network Services
- DHCP
- DNS
- HTTP / HTTPS Server

### 🔹 Security
- Firewall
- Port Security
- Spoofing Protection

### 🔹 Additional Features
- VoIP
- IoT Network
- Subnetting
