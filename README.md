# CCNA Enterprise Network Project

## 📌 Overview
This project simulates a real-world enterprise network for a company with two connected branches and Internet access using Cisco Packet Tracer.

The project demonstrates routing, switching, VLAN segmentation, network services, security implementation, VoIP integration, and enterprise network design.

---

#  Network Topology

The network consists of:
- Multiple departments connected through switches
- VLAN segmentation
- Inter-VLAN communication
- Centralized network services
- WAN connectivity between branches
- Internet access
- VoIP and IoT integration
